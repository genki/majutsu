## summary

- Event-driven snapshot and live-diff synchronization can limit filesystem
  scans to the roots touched by a filesystem event, while unknown-path and
  recovery paths retain the full-root safety fallback.
- `sync --wait` rechecks durable journal entries that arrive after local and
  remote snapshot heads already match, closing a late-event protection gap.
- Watch auto-prune is rate-limited, runs outside the synchronization hot path,
  and uses a process identity marker to prevent overlapping maintenance jobs.
- Prune metadata discovery uses the snapshot payload index when complete and
  avoids treating missing local recovery objects as pack candidates. Tracking
  metadata changes are committed transactionally.
- Health pins the snapshot being checked, reports paths that became excluded by
  current root rules, and distinguishes objects still being published from
  objects missing after synchronization has settled.
- Default excludes now cover directory entries and Python bytecode without
  overmatching similarly named source files. Config and age keyring reads are
  cached by file signature for repeated CLI and daemon operations.
- Remote builder installation uses a majutsu-specific worker name so it does
  not overwrite the generic build-service worker on machinaai.
