# majutsu v0.8.1

v0.8.0のcluster protocol v2とmaster-local durable storeを維持するpatch release。

## 修正

- cluster外部通知commandの失敗attempt時刻と連続失敗数を永続化する。失敗した通知は同じissueに
  対して60秒から最大3,600秒まで指数backoffし、pollごとの過剰な再実行を防ぐ。
- 通知成功時には失敗回数をresetし、既存の成功通知rate limitを維持する。
- 既存markerの形式を後方互換で読み込み、旧versionからのupgradeで通知状態を壊さない。
- prune時のdirectory metadata変更を検証するintegration testがno-op snapshotを明示的に許可し、
  suite全体の実行条件を安定させる。

## 互換性

cluster protocolはv2のままで、master/slave間のwire formatおよびACK意味論に変更はない。
更新時もslave queueとmaster backend queueを保持し、通常のmaster-first更新手順を使う。
