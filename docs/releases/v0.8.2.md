# majutsu v0.8.2

v0.8.1のcluster protocol v2とmaster-local durable storeを維持するpatch release。

## 修正

- 同一hostに未送信PUTが残っている間は対応するDELETEをbackend flush候補から除外する。
  これにより、先頭batchが保留中のDELETEだけで埋まって後続PUTが永久にstarveする問題を修正する。
- PUTの公開完了後は、次のpollから同hostのDELETEも通常どおり処理できる。
- pending DELETEがbatch上限を超える状況を作り、PUTが先にflushされる回帰テストを追加する。

## 互換性・更新手順

cluster protocolはv2のままで、wire format、ACK意味論、永続queue形式に変更はない。
更新時はslave daemonを停止してqueueを保持し、masterを先行更新してからslaveを更新する。
