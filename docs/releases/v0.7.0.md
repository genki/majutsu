# majutsu v0.7.0 release evidence

## release

- version: 0.7.0
- date: 2026-07-27 JST
- version output: `mj 0.7.0`

## summary

- Durable filesystem journals and their payloads are now uploaded before the
  full snapshot publication path, reducing the interval in which current
  changes are not remotely protected.
- Health reports distinguish a durable journal catch-up from an actual
  unprotected remote-head failure.
- Metadata-only snapshots no longer churn on directory mtime noise from
  excluded or transient files.
- Remotely acknowledged loose blobs and large-file chunks are reused without
  recreating redundant local payload cache.
- Empty operation summaries remain distinguishable from missing historical
  metadata after retention pruning.
- `mj root list` now uses the actual terminal width before deciding whether a
  horizontally scrollable pager is required.
- Snapshot retention pruning now automatically collects local objects made
  unreachable by deleted snapshots.

## runtime evidence

The 18-root vagrant environment was checked after installing the release
candidate:

- protection state: `protected`
- all roots synchronized
- upload queue and durable journal pending counts: 0
- local and remote current snapshots matched
- sampled remote fsck reported no missing objects
- automatic retention prune deleted two snapshots and immediately collected
  11 newly unreachable local objects
- no-op snapshot elapsed time improved from 14.57 seconds to 5.11 seconds in
  the metadata-only regression benchmark
