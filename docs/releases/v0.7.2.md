# majutsu v0.7.2 release evidence

## release

- version: 0.7.2
- date: 2026-08-27 JST
- version output: `mj 0.7.2`

## summary

- S3/GCS-compatible remotes now schedule remote prune from elapsed time instead
  of running a full backend-prefix cleanup whenever a snapshot changes. The
  default interval is one hour.
- Metadata export, chunk-index shard, and GC-mark uploads use stable logical
  fingerprints. Timestamp-only changes no longer cause redundant PUT requests.
- Unchanged GC marks are skipped on ordinary S3/GCS-compatible syncs while
  prune-triggered synchronization still publishes the latest protection set.
- File remotes retain their existing immediate cleanup and upload behavior.
