# majutsu v0.8.3

v0.8.2のcluster protocol v2とmaster-local durable storeを維持するpatch release。

## 修正

- backend lag通知は、同一hostの低優先度PUTにブロックされていない最古itemを基準に判定する。
  これにより、送信順序を保つため意図的に待機中の古いrefが、処理中のmetadata backlogを
  誤って長期滞留として通知する問題を修正する。
- `mj cluster status`とPrometheus metricsに、queue全体の最古時刻とは別に、ブロックされていない
  最古時刻と経過秒数を追加する。
- 古いrefが新しいmetadataの後ろで待機するケースの回帰テストを追加する。

## 互換性

cluster protocol、ACK意味論、backend queue形式は変更しない。status JSONへのfield追加は後方互換で、
v0.8.2以前のslaveは更新不要。masterだけを更新してもslaveとの通信を継続できる。
