# root listの端末幅誤判定

## 症状

`mj root list`の出力行数が端末高さ以下で、表示幅にも余裕がある端末において、
横スクロール用ページャーが起動する場合があった。

## 原因

`root list`だけは`COLUMNS`が未設定の場合に実端末幅を取得せず、常に100列としていた。
そのため100列を超える行があると、実端末が十分に広くても幅超過と誤判定していた。

## 修正

- `COLUMNS`が有効ならそれを優先する。
- 未設定または不正なら`crossterm::terminal::size()`で実端末幅を取得する。
- どちらも利用できない非TTY環境だけ100列へフォールバックする。
- 幅取得の優先順位を単体テストで固定する。

横幅を超える場合はPATHを省略せず確認できるよう、従来どおり横スクロール可能な
ページャーを使用する。`--pager`と`--no-pager`の明示指定も維持する。
